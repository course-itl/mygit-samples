# mygit-samples

Учебные файлы для недели «git своими руками» курса информатики.

В корне лежат три файла:

- `example.txt` — короткий русский текст в UTF-8,
- `empty.bin` — совершенно пустой файл,
- `binary.bin` — четыре байта, среди которых есть нулевой.

Файл `.gitattributes` запрещает любое преобразование переводов строк, поэтому
при клонировании эти файлы на любой ОС состоят ровно из тех же байтов, что и здесь.
